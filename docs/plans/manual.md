# Element Manual — Completion Plan

Status of this document: living checklist for finishing the Element User Manual.
It captures an audit of the current manual (what is irrelevant, what is broken,
what is missing) and a phased plan to complete it. Check items off as they land.

The manual is built with Sphinx (reStructuredText + MyST markdown) and published
on Read the Docs. `index.rst` is the master document.

---

## Audit summary

The manual is currently an early skeleton (~1,400 lines, 6 screenshots) and the
index page is flagged "under construction." It documents several peripheral
features but omits the core of the application (sessions, graphs, nodes,
connecting, MIDI mapping). A large part of the glossary was copied from an
unrelated DJ application and does not apply to Element.

## Phase 1 — Getting Started & core concepts

The foundational chapters that everything else depends on. Currently absent.

- [ ] **Getting Started** — download/install per platform, first launch, a quick
      "load a plugin and make sound" walkthrough for both standalone and plugin.
- [ ] **Core Concepts** — the Session ↔ Graph ↔ Node ↔ Subgraph model. This is
      the mental model the rest of the manual assumes; it must come early.
- [ ] **The Interface** — main window tour, content views, and the Navigation
      pane (Plugins tree vs Session tree).

---

## Phase 2 — Core workflows

- [ ] **Graph Editor** — adding nodes, connecting ports, arranging, and the node
      context menu (duplicate, remove, disconnect all/inputs/outputs/MIDI, mute
      input ports, color, replace-with-plugin, oversampling Off/2x/4x/8x).
- [ ] **Patch Bay** — the connection matrix view.
- [ ] **Graph Mixer**, **Node Channel Strip**, **Meter Bridge**.
- [ ] **Sessions** — new/open/save/save-as, Import/Export graph (Session Import
      Wizard), session settings (name, tempo, notes).
- [ ] **Transport** — play/stop/record, tempo & meter bar.
- [ ] **MIDI Controller Mapping / MIDI Learn** — capturing a CC/note and binding
      it to a parameter; the MIDI Mappings view (Device/Node/Parameter table).
      (The introduction advertises this feature but it is undocumented.)
- [ ] **Keymap customization** — the Key Mappings editor for rebinding command
      shortcuts. (Today only virtual-keyboard keys are listed.)
- [ ] **Subgraphs / nested graphs**.
- [ ] **Node presets & factory presets** — save/recall/save-as-default/reset.
- [ ] **Undo/Redo**.

- [ ] **Node Reference** (largest single content job) — one short entry per

          MIDI Program Map, MIDI Monitor, OSC Sender, OSC Receiver, Script,
          MCU / Mackie Control.

          Reverb, EQ Filter, Frequency Splitter, Compressor, Audio Mixer,
