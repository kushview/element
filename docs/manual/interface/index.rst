The Interface
=============

|El| runs in a single main window. A sidebar of panels on the left shows the
session, the graph being edited and the selected node. The content area on
the right holds the graph editor or one of the other main views, with an
optional accessory view and the virtual keyboard beneath it. A toolbar and a
status bar frame the whole thing.

This part is a reference to that window. It names every panel, view, menu
item and button, says what each one does, and gives its default keyboard
shortcut. Turn to it when you can see something on screen and want to know
what it is for. The chapters in :ref:`part-using` are the other way round:
they start from a task and refer back here for the controls involved.
