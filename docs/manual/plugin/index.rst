Element as a Plugin
===================

The plugin editions put the |El| engine inside a DAW or other host. They open
the same sessions and graphs as the standalone application, and the
interface is the same main window, so everything in the earlier parts
applies. This part covers only the differences.

   performance parameters exposed to the host, and sharing sessions between
