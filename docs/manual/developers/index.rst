Developers
==========

This part is for anyone who wants to build |El| from source, whether to run
the newest code, to contribute a fix, or to package it for a platform. The
project is free software; the `source repository`_ and the `issue tracker`_
are the places to start. Nothing here is needed to use |El|.

:doc:`building`
   Getting the sources and submodules, and building with CMake on each
   platform.

:doc:`code-style`
   The C++ conventions used in the project, adapted from JUCE.

:doc:`lua-style`
   The conventions for the Lua modules and scripts.
