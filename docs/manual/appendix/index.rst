Appendices
==========

.. raw:: latex

   \appendix

Reference tables and lists for looking things up: the default keyboard
shortcuts, the OSC addresses, the file types |El| reads and writes and where
it keeps them, the answers to common problems, and the glossary that
defines the terms used throughout the manual.

:doc:`shortcuts`
   The default shortcuts of the standalone application, by menu.

:doc:`osc-commands`
   The addresses accepted by the OSC host and used by the OSC nodes.

:doc:`files-and-locations`
   File types, the user library, settings and application data, plugin
   locations and the command line.

:doc:`troubleshooting`
   Log files, start-up and crash recovery, missing sound, plugin problems,
   stuck notes, and where to get help.

:doc:`glossary`
   Definitions of the terms used in this manual.
